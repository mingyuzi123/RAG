# PDF 语义切分首轮对照

在 RFC 9111 和 Landsat 9 的冻结题上对比默认 PDF 段落切分与实验 `semantic`。沿用两份原始 PDF、相同的 E5 检索、候选前 10、最多 3 个上下文块。对 16 道可回答题，按原页和抽取行范围检查全部标注证据是否齐全，R07 接受附录提供的替代证据。4 道无答案题只记录候选，不计入覆盖率。[原始冻结题与答案验收](V1_ACCEPTANCE.md)

实验规则先按原方式切块，再用同一固定版本 E5 给页内块编码。两个相邻块的余弦相似度达到 0.82，合并后不超过 1800 字符，才考虑成对合并。识别到表格标记的页面保留原切法；不合并进入新编号章节或 Markdown 标题的边界，并跳过识别到的宽间距页眉页脚。标题和表格保护是启发式规则。合并保留原文与页码，重新生成块 ID，单独写索引。

## 结果

| 资料 | 块数 | 前 10 集齐标注证据 | 直接取前 3 集齐 | 等字符预算内集齐 |
| --- | ---: | ---: | ---: | ---: |
| RFC 9111 | 533 → 381 | 5/8 → 5/8 | 1/8 → 4/8 | 1/8 → 1/8 |
| Landsat 9 | 12 → 11 | 8/8 → 8/8 | 3/8 → 4/8 | 3/8 → 4/8 |
| 合计 | 545 → 392 | 13/16 → 13/16 | 4/16 → 8/16 | 4/16 → 5/16 |

等预算口径将每题基线前三块的正文总字符数作为该题上限。在实验组的前三块里按排名装入完整块，跳过放不下的块。字符数是预算代理，提示词额外开销与实际 token 另计。

| 案例 | 变化 |
| --- | --- |
| R01 | 两条 Vary 规则进入同一块，等预算下新增完整覆盖。 |
| R03 | 第 17 页的引导句和原第 4 名的两条规则合成 566 字符的第 1 名；基线上下文只有 292 字符，新块放不下。两条规则原来的独立块也有 441 字符。 |
| R04 | 基线前 10 能找到完整的新鲜期计算规则，合并后跌出前 10。 |
| R05 | Age 定义进了直接前三，但等预算下只装入了驻留时间证据。 |
| R07 | 原来可用主文加附录覆盖两条规则。合并后的规范块虽然排第 1，却超过原预算，失去完整覆盖。 |
| U01 | 第 1 页轨道参数升到第 3，且能放进等预算上下文。 |
| U05 | 第 2 页含表格，保持原切法，波段和脚注仍同时入选。 |

保留默认段落切分。等预算下实际新增 R01、U01，退步 R07。前 10 总数持平，但 R01 改善、R04 退步。RFC 9111 一次本机建索引从约 7.1 秒到 15.2 秒，包含实验模式额外加载模型的时间；这里没有做多次计时。

## 三道覆盖变化题的真实问答

挑出等预算覆盖改变的 R01、R07、U01。每题每种策略用同一个 DeepSeek 模型和生成提示词各生成一次，六次共 5004 tokens，逐条复核主要断言的引用。

| 题号 | 段落切分 | 语义切分 |
| --- | --- | --- |
| R01 | 只答出通配符规则，引用第 11 页。 | 两项均答全，第 11 页同一个块支持两条规则。 |
| R07 | 两项均答全，第 19 页和第 32 页附录支持结论。 | 仅收到第 14 页年龄计算片段，回答说明证据不足。 |
| U01 | 提供的摘录没有两个轨道参数，回答说明证据不足。 | 答出 705 公里、98.2 度，第 1 页支持两项。 |

这一组完整回答从 1/3 到 2/3。三题是看过覆盖变化后选的诊断样本，不能当作全题集准确率。无答案题未重新调用生成模型。

## 复现

按 [V1 验收](V1_ACCEPTANCE.md#复现) 下载相同的两份 PDF。在仓库根目录执行下列命令。脚本使用本地 E5，在 `logs/` 建立隔离索引，并输出证据行范围、候选、入选排名和字符预算。首次使用 E5 时需要下载模型。

```powershell
.\.venv\Scripts\python.exe scripts/compare_pdf_semantic.py logs/v1-acceptance/rfc9111.pdf --cases reports/V1_RFC9111_CASES.json --output logs/semantic-rfc.json
.\.venv\Scripts\python.exe scripts/compare_pdf_semantic.py logs/v1-acceptance/fs20193008.pdf --cases reports/V1_LANDSAT_CASES.json --output logs/semantic-landsat.json
```

如需复测问答，用新的输出文件名，在 RFC 命令末尾加 `--answer-case R01 --answer-case R07`，在 Landsat 命令末尾加 `--answer-case U01`。需配置本机 DeepSeek 密钥，会真实调用 API。
